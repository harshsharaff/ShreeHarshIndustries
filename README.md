# Shree Harsh Industries

Corrugated box manufacturer in Tumkur, Karnataka. Fully automatic 5-ply plant — custom sizes, in-house testing, own transport.

**Live site:** https://harshsharaff.github.io/ShreeHarshIndustries/

## Development

Needs Node.js (or Bun) and npm.

```sh
git clone https://github.com/harshsharaff/ShreeHarshIndustries.git
cd ShreeHarshIndustries
npm i
npm run dev
```

## Deploy

Pushes to `main` build a static site and publish it on GitHub Pages (`/ShreeHarshIndustries/`).
